# AI电子书阅读器小程序

## 项目概述

这是一个基于微信小程序开发的AI电子书阅读器，提供了丰富的阅读功能和用户体验，支持多种文件格式、智能翻页、缩略图导航等功能。

## 功能特性

### 核心阅读功能
- **触摸翻页**：支持左右滑动翻页，模拟真实书本翻页效果
- **自动翻页**：可设置自动翻页功能，解放双手
- **缩略图导航**：生成书籍缩略图，支持快速跳转
- **页面跳转**：可直接输入页码跳转到指定页面
- **智能缩放**：支持内容缩放，适应不同阅读需求

### 文件管理功能
- **多格式支持**：支持PDF、Word、Excel、PPT、图片、文本等多种文件格式
- **文件上传**：通过微信文件选择器上传本地文件
- **文件预览**：查看上传文件的详细信息并打开预览
- **最近文件**：快速访问最近上传的文件

### 界面与交互
- **顶部菜单**：提供文本编辑、搜索、设置等功能入口
- **圆形菜单**：包含分享、自动翻页、音效等快捷操作
- **上传菜单**：选择不同类型的文件进行上传
- **音效控制**：可开启或关闭翻页音效
- **缩略图控制**：可显示或隐藏缩略图

### 其他功能
- **分享功能**：生成分享海报、二维码等分享选项
- **同学画功能**：查看其他同学的阅读笔记和标注
- **书籍目录**：查看书籍的章节结构
- **作者信息**：查看书籍的作者和出版信息
- **使用帮助**：提供阅读器的使用说明
- **版本信息**：显示当前版本和功能介绍

## 核心文件说明

### pages/index/index.js
主页面逻辑文件，包含所有核心功能的实现：
- 页面生命周期管理
- 触摸事件处理
- 翻页控制
- 缩略图管理
- 文件上传和预览
- 菜单控制
- 自动翻页功能

### app.js
小程序入口文件，管理全局生命周期和全局数据：
- 小程序启动、显示、隐藏时的处理
- 全局数据共享

### utils/util.js
工具函数模块，提供常用的格式化和辅助函数：
- formatTime：格式化日期时间
- formatNumber：格式化数字为两位数

## 维护指南

### 代码结构
- 采用模块化设计，功能按模块划分
- 使用清晰的命名规范，便于理解和维护
- 添加详细的注释，解释代码功能和逻辑

### 数据存储
- 使用微信小程序的本地存储API保存用户设置和上传文件
- 定期清理过期数据，避免占用过多存储空间

### 性能优化
- 避免频繁调用setData，减少页面重渲染
- 合理使用定时器，确保及时清理避免内存泄漏
- 图片资源优化，避免使用过大的图片

### 常见问题处理
1. **翻页动画卡顿**：
   - 检查是否有过多的setData调用
   - 优化动画逻辑，减少计算量

2. **文件上传失败**：
   - 检查文件大小是否超过限制
   - 确认网络连接正常
   - 检查文件格式是否支持

3. **缩略图显示异常**：
   - 检查缩略图生成逻辑
   - 确认图片资源是否可访问

## 优化建议

### 性能优化
1. **图片懒加载**：只加载当前页面和相邻页面的图片，减少初始加载时间
2. **文件预加载**：提前加载下一页内容，提升翻页流畅度
3. **数据缓存**：对常用数据进行缓存，减少重复请求
4. **组件化改造**：将页面拆分为多个组件，提高代码复用性和维护性

### 功能优化
1. **阅读进度同步**：支持多设备阅读进度同步
2. **书签功能**：添加书签功能，方便标记重要页面
3. **笔记功能**：支持在页面上添加笔记和标注
4. **搜索功能**：实现文本内容搜索，快速定位关键词
5. **夜间模式**：添加夜间阅读模式，保护视力

### 用户体验优化
1. **手势支持**：增加更多手势操作，如双击缩放、长按菜单等
2. **字体和主题**：支持自定义字体、字号和阅读主题
3. **翻页效果**：提供多种翻页效果选择
4. **进度显示**：在页面上显示当前阅读进度

- 微信开发者工具

## 安装与运行

1. 克隆项目到本地
2. 打开微信开发者工具
3. 导入项目
4. 配置小程序AppID
5. 点击运行即可在模拟器中查看效果
